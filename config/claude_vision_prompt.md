# 政治資金収支報告書 OCR画像解析指示書

この画像は日本の政治資金収支報告書の1ページです。
以下の手順およびルールに従って画像解析を行い、指定のJSON形式のみで回答してください。

## 1. 様式番号および様式枝番の特定

画像内から様式番号および様式枝番を特定してください。

### 様式番号の判定

- 画像内の見出し（「（その1）」「（その2）」〜「（その20）」など）から番号を取得してください。
- 監査意見書、監査報告書、または「その～」が存在しない対象外ページの場合は、様式番号および様式枝番を `null`、XMLを空文字列 `""` としてください。

### 様式枝番の判定

- **その7, その8, その11, その12 (寄附等の内訳)**:
  - 1: 個人
  - 2: 法人その他の団体
  - 3: 政治団体
- **その14 (経常経費の内訳)**:
  - 2: 光熱水費
  - 3: 備品・消耗品費
  - 4: 事務所費
- **その15 (政治活動費の内訳)**:
  - 1: 組織活動費（組織対策費、渉外費、行事費など）
  - 2: 選挙関係費
  - 3: 機関紙発行事業費
  - 4: 宣伝事業費
  - 5: 政治資金パーティー開催事業費
  - 6: その他の事業費
  - 7: 調査研究費
  - 8: 寄付・交付金（寄付金、交付金など）
  - 9: その他の経費
- **その18 (資産等の内訳)**:
  - 1〜12 (土地、建物、地上権、動産など)

## 2. テンプレートの選択と部分XML生成ルール

特定した【様式番号】および【様式枝番】をキーとして、後述の「収支報告書XMLテンプレート一覧」から一致するテンプレートを1つ選択してください。
選択したテンプレートのタグ名（`<SYUUSHI07_XX>`, `<SHEET>`, `<ROW>` 等の大文字半角英数字）および階層構造を厳密に保持し、画像内の値（文字・数字・日付・金額等）を読み取って各タグ内に埋め込んでください。

### 【重要】タグ名の遵守ルール

- 画像内の見出しや項目名から勝手なXMLタグ名（例: `<資産等の状況>`, `<資産等の有無>`, `<ア土地有無>` 等）を作成することは厳正に禁止します。
- 必ず選択したテンプレート内に定義されているタグ名（例: `<SYUUSHI07_17>`, `<TOCHI_UMU>` 等）のみを使用してください。

### 表形式の様式（行データが存在する様式、テンプレート名に _row が含まれるもの）のルール

1. **行データが複数存在する場合**:
   `<ROW>` 〜 `</ROW>` タグを画像内の表行数分複製し、各行に該当する値を設定してください。
2. **行データが存在しない場合（表に行記載がなく、ページ計・合計金額のみが存在する場合など）**:
   `<ROW>` 〜 `</ROW>` タグを削除したXMLとしてください。

### 行データが存在しない様式（テンプレート名に _row が含まれないもの、例: その1, その2, その13, その16, その17, その20 など）のルール

- タグの増減は一切行わず、各タグ内に画像から読み取った対応する値を設定してください（有無項目は 0 または 1 など）。

## 3. 出力フォーマット

Markdownのコードブロック（```json など）や前後の解説文は含めず、以下のJSON形式のみを出力してください:

{
  "form_number": <int または null>,
  "branch_number": <int または null>,
  "xml": "<生成された部分XML文字列>"
}
